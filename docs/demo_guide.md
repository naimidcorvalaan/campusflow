# CampusFlow：3–5分钟比赛演示

定位只说一句：**tjuer专属的校园时空规划系统**。
演示重点是校园移动与实际执行一起计算，以及用户少整理信息就能开始。

## 现场主线

使用电脑，提前确认TJU文本接口可用。不要现场展示.env或密钥。
主线采用卫津路、14:00参考时间；正式演示可按当天日期设置。
先用一句短话解释需求：“有课程、要吃饭、还有作业，移动时间也得算进去。”

| 时间 | 操作与输入 | 看哪里 / 证明什么 |
|---|---|---|
| 0:00–0:30 | 打开首页，指出主输入和可选当前位置 | 不必先配置个人设置或填写任务表 |
| 0:30–1:40 | 输入下方完整演示文本，点“帮我安排” | 唯一当前方案：学习、饭、路上时间、18:50到楼、18:55到教室、19:00上课 |
| 1:40–2:30 | 反馈“作业还剩40分钟，我现在在图书馆。”，点“更新方案” | 剩余工作重新安排，固定课程保留，位置参与路线；安排不等于已完成 |
| 2:30–3:40 | 展开“难以估计任务时间？让campusflow帮你估”，粘贴下方群聊原文，点“帮我看看” | 同一入口整理范围并估时；不猜相对日期；确认才入计划 |
| 3:40–4:20 | 可选打开个人设置，展示偏好/课表 | 保存一次，下次少输入；设置保存不立即重排 |

初始完整演示文本（明确数字只用于这份演示资料）：

> 在图书馆写90分钟作业，然后背60分钟单词，可以拆开。19:00去9教上课，上一小时半，上课前吃晚饭。

平时用户可以只说“晚上七点在9教上课，课前想吃饭，还有高数作业想做一点”。
已有课表会补当天课程；缺关键事实才确认，没写用时可以暂估。不要在有限演示时间里要求观众核对所有边界。

原始通知：

> @所有人 第三章作业周五之前交哈，3-12，8题过程写全，还是学习通那个入口，别忘了

这一幕停在可读草稿即可说明价值。如果继续确认，演示者要自己确认收到日期/具体截止，
或明确选择暂不把它作为约束，不能为了省输入编造日期。
结果直接给出范围与粗略用时；用户可补充情况后重估，确认后再“确认并加入计划”。
未来日期的固定安排不自动跨日加入当前日。

## 讲述要点

- “移动时间在任务之间实际占用日程，19:00课程要求分清到楼和到教室。”
- “已经做完多少来自用户反馈；计划里排过不代表做完。”
- “我可以原样贴通知，只处理缺少的关键事实。”
- “课表和常用地点保存后，下次不用再抄；宿舍不代表我现在就在宿舍。”

路线由仓库静态校园图计算，数据基于高德来源；不要说实时高德导航、实时路况或实时食堂排队。
Qwen理解任务、顺序和意图；程序计算时间、路线、进度、校区并校验正式方案。

备选亮点（有余时再演示）：在反馈框说
“如果改成先背单词，再写作业，会怎么安排？先给我看看，暂时不要改。”
预览与当前方案分开；采用同一候选，“保持现在方案”丢弃预览。不要主线里把所有功能都点一遍。

## API失败时

保留旧方案和输入，简短说明学校服务当前不可达。
切到**明确注明合成数据的离线排练**展示交互，不能将其当作真实服务成功。
图片接口级能力已用无敏感合成图真实验证；复杂任务图和二维课表仍以网页预览、用户确认为准，演示时不宣传自动准确导入。

## 无API排练

在已安装环境下，维护者可运行：

```powershell
.venv\Scripts\python.exe scripts\launch_campusflow.py --offline-demo --port 8542
```

打开 `http://127.0.0.1:8542/?profile=release&presentation=1`。
按上表完整文本和反馈操作；这个离线入口只有有限合成响应，不能当万能模型使用。
它调用同一正式live入口、controller、地图、时间线和SQLite，仅最低模型响应被替换。
页面轻标“展示样例 · 合成数据”，不显示调试面板。正常用户入口没有这项开关。
`presentation=1` 只隐藏开发控件，不改变计划内容或伪装模型请求。

离线进程阻断外部HTTP及dotenv读取，使用系统临时 `campusflow-rehearsal-*` 目录。
同服务重开会恢复合成档案；服务重启后默认新临时目录。
演练重启恢复时，维护者可把 `CAMPUSFLOW_PREVIEW_DATA_DIR` 指向同一个系统临时 `campusflow-rehearsal-*` 目录；
入口拒绝其他目录，不读取用户正式CAMPUSFLOW_DATA_DIR。

其他已有排练路径：`?identity=anonymous&low_input=a` 展示短输入；
`?identity=anonymous&material=dirty_a` 展示通知。查询参数只存在于离线入口。

## 调用边界（给演示维护者）

| 操作 | 是否调用模型 |
|---|---|
| 打开、编辑、关闭、保存设置、恢复、补通知日期 | 0 |
| 初始安排、执行反馈、刷新、What-if预览 | 现有有界规划流程 |
| 难以估计任务时间？让campusflow帮你估（文字/图片） | 显式“帮我看看”通常1次，格式修复最多额外1次；主动重估再调用1次 |
| 识别课表文字/截图 | 显式识别通常1次，格式修复最多额外1次 |
| 确认并安排 / 加入今日计划 | 不再理解原材料或重新估时；调用现有规划流程 |
| 采用 / 保持What-if | 0 |

离线入口以上操作均为fake调用，不接真实服务。正式服务的多步规划预算不能说成“只调用一次”。
