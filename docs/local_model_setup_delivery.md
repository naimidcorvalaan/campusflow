# 本地首次启动模型配置交付记录

## 使用体验

Windows 用户安装 Python 3.12 后双击「启动 CampusFlow.bat」。缺少配置时显示「连接 TJU 模型服务」，填写 API 地址、模型名称和 API Key 后保存，即可进入原工作台；不再需要复制或编辑 `.env`。模型名默认 `tju-llm`，地址使用学校提供的信息。

可以「暂时跳过，先看看」。此时页面和手动设置可用，规划等模型操作会提示先连接服务，保留已有输入和方案。不会自动启用 mock。

以后在「个人设置 → 我的偏好 → TJU 模型服务」修改或清除。已存 Key 不回显；留空保留，填写新值更新。保存立即生效，不需要重启。保存和「测试已保存的连接」分开，后者仅在用户主动点击时发起一次短请求；网络失败不删除配置，也不展示模型返回正文。

## 持久化与兼容

- 默认文件：`%LOCALAPPDATA%\CampusFlow\model-service.json`。
- 使用现有平台数据目录规则；高级用户设置 `CAMPUSFLOW_DATA_DIR` 时随该目录保存。为了跨目录升级，应保持该目录不变；自定义值推荐使用绝对路径。
- 文件与业务 SQLite 独立，不改变数据库 schema、任务、课表、偏好或档案。
- 优先级：进程环境变量 → 原 `.env` 加载器 → 本机文件补齐缺失字段。文件内容不注入环境变量，不缓存 Key，因此更新和清除不会留下进程中的旧值。
- 已有完整配置直接进入工作台；页面不覆盖 `.env` 或进程变量，不把外部字段复制到本机配置。外部字段在编辑器中只读，由原来源维护。
- TJU 仍是默认；显式 DeepSeek 配置继续通过原 Provider 分支，TJU 引导和编辑器不会出现。Provider、planner、P5、materials、map 和 SQLite schema 未重写。

## 安全边界

编辑器只在服务绑定 `127.0.0.1`、`localhost` 或 `::1` 且 Provider 为 TJU 时开放。公开或局域网绑定的服务不提供此编辑器。

Key 使用 password 控件，成功保存或清除后清空输入，已有 Key 不回填。配置错误使用固定消息；连接测试不回显响应正文、异常正文或 Key。输入校验拒绝带登录信息、query、fragment 的地址，以及把同一 Key 填入 URL 或模型名称的情况；远端地址要求 HTTPS。

文件采用临时文件加原子替换，写入失败保留原配置。损坏文件可以重新保存或清除。模型配置文件和临时文件已加入 Git 忽略及源码包排除规则。

这是本机文件持久化，**不是加密保险库**。文件包含明文 Key，依靠当前操作系统用户目录权限保护；有权读取该用户文件的进程仍能读到它。不要共享、提交或复制该文件给他人。没有把 Key 写入业务 SQLite，没有调用真实 TJU / DeepSeek，没有截取任何真实 Key。
