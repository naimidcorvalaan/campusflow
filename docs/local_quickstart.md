# 在Windows打开 CampusFlow

## 第一次使用

1. 从 Python 官方下载64位 **Python 3.12**，安装时勾选 **Add python.exe to PATH**。已有3.8–3.12可用，3.9.7除外。当前Streamlit保持1.31.1。
2. 完整解压CampusFlow到自己可写的文件夹；不要在压缩软件里直接双击文件。
3. 双击 **启动 CampusFlow.bat**。中文入口无法打开时，用同目录英文入口 `start_campusflow.bat`。
4. 首次创建 `.venv`，随后联网安装依赖。窗口会显示准备/下载/使用缓存/安装阶段；30秒没有新阶段时显示真实等待时长。不要把等待误当成无响应。
5. 页面就绪后自动打开浏览器。默认只在本电脑的 `http://127.0.0.1:8501` 访问，不改防火墙、代理或VPN。

首次安装时间取决于网络和软件缓存，不能保证几分钟完成。一次最多等待10分钟；
超时、断网或Ctrl+C后重新双击，会核对已经安装的依赖并重试，不删除原环境或个人档案。
pip可能复用已有下载缓存；它仍会重新检查需要的依赖。已有非空但损坏的环境不会被覆盖。

## 日常启动和退出

再次双击会核对已安装版本，匹配时不运行pip。重复双击打开已运行的页面，准备中则提示看原窗口，
不会同时启动多份服务。若8501属于其他程序，启动器报端口占用，不结束那个程序。

使用期间保留启动窗口；关闭网页只是关闭页面。按Ctrl+C或关闭启动窗口结束本次服务，
重新双击可启动。Windows下启动器用操作系统进程组管理其页面子进程，避免关闭后留下一份后台服务。

## 配置学校模型：只需一次

模型服务配置属于本机，和个人档案分开。没有配置也能打开界面、编辑设置。

1. 在项目文件夹找到 `.env.example`，复制一份，重命名为 **.env**。
2. 用记事本打开副本，把学校分配的三个值分别填在等号后：
   - `TJU_LLM_BASE_URL`：比赛项目专属接口地址。
   - `TJU_LLM_MODEL`：学校提供的模型标识。
   - `TJU_LLM_API_KEY`：对应密钥。
3. 保存，关闭启动窗口，再双击启动。

文件扩展名不可隐藏成 `.env.txt`。Windows资源管理器可在“查看 → 显示 → 文件扩展名”核对。
最后的 `CAMPUSFLOW_DATA_DIR=` 本机使用可留空。
这不是个人设置字段；不要把密钥写入任务、课表、聊天或学号档案，不要分享自己的.env。
当前使用本机文件配置，没有网页密钥编辑器；进程环境变量优先于.env，已有环境变量由配置者维护。

真实生成计划需满足学校账号和校园网/VPN等网络条件。本地页面能打开不等于学校模型服务可访问。
配置值是否正确由第一次明确操作实际检验，启动器不偷偷调用模型探测。

## 得到第一份计划

直接输入一句今天想做的事。默认北洋园、步行、适当穿插休息与当前时间；个人设置不必先填。
当前位置可空，只有需要路线时才确认位置。课程开始、明确deadline、地点冲突仍要核对，
课程结束未知时不编造课后时间。

已有模型能估计工作量时标注AI暂估；无法估计时保留未知，不会偷偷补成60分钟。
简单任务、原始通知和单张任务图片统一从“难以估计任务时间？让campusflow帮你估”进入；先看摘要和估时，只有真有问题才修改。
确认草稿后才加入并更新正式方案，已安排时长不会记成实际完成。

## 保存与重开

临时使用不要求学号，只保存当前浏览器会话。需要下次继续时，在个人设置开启个性化并选择档案；
以后重新打开选择同一档案。学号只是本机档案标识，不是认证。

Windows默认数据目录为 `%LOCALAPPDATA%\CampusFlow`，不会保存在下载的源码目录里。
关闭或重启不自动完成任务、不重新调用模型。过期方案显示原参考时间，用户明确更新后再规划。
复制项目给同学不应包含自己.env或数据库；源码包构建脚本会排除这些本地文件。

## 常见情况

| 窗口/页面提示 | 下一步 |
|---|---|
| 未找到Python / 版本不兼容 | 安装64位Python3.12并勾选PATH，然后重开；3.9.7不受当前Streamlit支持 |
| 软件源网络失败或超时 | 检查当前网络后重新双击；可保留“阶段、错误类别、退出码”求助，不发送配置值 |
| 证书校验失败 | 核对本机网络/证书环境；不要关闭证书校验 |
| 超过10分钟 | 本次安装已结束，可以安全重试；不无限等待 |
| 环境已有文件但无法使用 | 保留原目录，找维护者检查；启动器不会清空或覆盖它 |
| 本地端口被占用 | 若是原CampusFlow打开原页面；其他程序占用时由用户决定如何处理 |
| 模型未配置 | 按上面的三项配置；页面仍能浏览 |
| 真实服务请求失败 | 保留输入和可靠方案，核对网络/账号后主动重试；不反复点击制造请求 |

以下命令只用于开发验证，普通使用不需要：

```powershell
.venv\Scripts\python.exe scripts\launch_campusflow.py --offline-demo --port 8542
.venv\Scripts\python.exe scripts\launch_campusflow.py --venv <独立临时目录> --prepare-only
```

离线演示不读取真实模型配置、阻断外部HTTP、使用临时档案。
