# CampusFlow v1.0.0-rc1

CampusFlow 首个 Windows Release Candidate：把任务、课程和校园移动放进同一条现实时间线。

- 当前行动规划：现在做什么、做到几点。
- 基于高德地图数据构建并本地化的北洋园 / 卫津路校园路网，校园移动进入计划。
- 动态重新规划：进度、位置或安排变化后继续规划。
- 任务估时：文字、图片、Word、PDF，并结合个人情况。
- 用户明确授权、程序校验的合法并行任务。
- 个性化设置、常用地点及课表截图导入。
- 首次页面连接 TJU 模型服务，保存一次后继续使用。
- Windows 一键启动，自动准备独立运行环境。

**使用方式**：安装 64 位 Python 3.12 → 下载并解压 `CampusFlow-v1.0.0-rc1-windows.zip` → 双击“启动 CampusFlow.bat” → 在页面填写自己的 TJU 服务地址、模型名称和 API Key → 开始使用。

首次依赖安装需要网络。校园路网随包提供，运行时不请求高德地图 API。服务密钥和个人数据不包含在发布包中。

此版本标记为 Pre-release，欢迎反馈可复现的问题。
