## 用户正常环境的新证据与手动入口

用户随后在正常PowerShell启动的正式 `src/p2_live_main.py` 页面中输入
“今天想整理20分钟笔记。”，真实生成“已安排现在整理笔记，做到15:02”。
这证明该正常PowerShell进程的正式live文本路径可用；Codex启动进程和独立诊断失败
不能覆盖这项证据。

图片验证必须由用户在同一个正常PowerShell环境中亲手执行：

```powershell
.\.venv\Scripts\python.exe scripts\verify_tju_image_capability.py image
```

脚本先调用正式页面相同的 `load_project_configuration`，再复用
`call_tju_llm_messages` 和当前 `image_url` Data URI格式。单次运行只发1次图片请求，
超时120秒，不重试；不改变base URL、模型或代理。终端输出HTTP响应状态、必要的
模型短回答、`314159`/圆形/蓝色三个判定和安全错误层级。
