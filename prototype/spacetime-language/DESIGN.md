## 数据生成与视觉表达

生成入口为 [build_assets.py](build_assets.py)，不复制或修改业务算法。

1. 使用 [现有 loader](../../src/p3_map_loader.py) 读取 [北洋园地图](../../data/beiyangyuan_map.json) 与 [卫津路地图](../../data/weijinlu_map.json)。原始数据分别为 129 点 / 404 边、141 点 / 168 边；卫津路 loader 会生成道路侧接入节点。
2. 调用 [plan_route](../../src/p3_route_provider.py)，使用现有按距离加权的 Dijkstra 和步行可用边。路径、每段距离、总距离与出行方式均从结果导出。原始路径 id、源文件 SHA-256、算法文件 SHA-256 保存在 生成后的 `assets/manifest.json`。
3. 调用 [estimate_travel_time](../../src/p3_time_estimator.py)，明确传 caller=None，走现有确定性 program_fallback 分支。步行中心值为 ceil(距离 / 75 m/min)；区间也保留现有函数返回值。两条核心路线分别为 11 分钟（9–13 分钟）和 7 分钟（6–9 分钟）。页面统一呈现「步行约 X 分钟」。
4. 收拾时间复用 TRANSITION_BUFFER_MINUTES=5；课程到楼准备复用 CLASS_ARRIVAL_LEAD_MINUTES=10。展示日程以 14:00 开始、作业 90 分钟、单词 60 分钟、19:00 上课为上下文。第一段从任务结束加收拾时间推出发时刻；第二段从课程到楼截止时刻反推。北洋园第一段为 16:30 收拾 → 16:35 出发 → 16:46 抵达；卫津路为 16:30 → 16:35 → 16:42。
5. [route_visual.js](route_visual.js) 是首页、移动状态和独立路线图共用的 SVG 绘制器。经纬度按校园中心纬度作局部等距近似投影，保持统一缩放与相对方位；路径高亮严格沿返回节点序列绘制。卫津路道路侧接入 id 映射到同坐标的源 POI，仅用于显示。仓库保存节点与连接而没有完整道路折线，因此采用风格化路径表达；近似坐标信息继续保留在数据中。
6. 背景淡路网使用现有步行 adjacency；两校区纹理和边带保留原来的源坐标与连接去重算法，文件哈希与上一版一致。纹理用于 sidebar、设计系统与展示素材，未增加产品工作区。

日程任务和四个界面状态是视觉上下文；路线与移动估时是当前程序的真实计算结果。移动页四种状态共用同一条路径，只改变起终点的状态表达，途中显示上次确认地点。

## 设计归档与复现

此目录保留设计说明和必要 HTML / CSS / JS / Python 源文件。正式页面已经完成迁移，当前产品素材见 [README](../../README.md)。原型不参与正式运行，也不进入 Windows Release ZIP。

生成的 assets、浏览器截图、历史校验 JSON 与一次性检查脚本不提交。首次查看归档前，在仓库根目录运行：

```powershell
python prototype/spacetime-language/build_assets.py
```

它使用当前两校区数据与现有路由/估时函数，重新生成 `assets/networks.js`、纹理 SVG 和 `assets/manifest.json`。随后打开 `index.html` 或 `routes.html`。生成目录已被 gitignore 排除。

设计阶段原有 44 项、新增浏览器 98 项、离线数据 56 项检查均通过；原始验收文件留在本地 ignored artifacts。公开归档只保留可理解和可再生成的设计成果。
